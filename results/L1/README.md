## Notes on the values (all derived from rows cited in the table)

- **Pressure amplitude against the lumped result.** The linear formula uses the measured cycle-mean pressure. For an
  isentropic volume oscillation of relative amplitude eps, the fundamental of p exceeds gamma p_m V1 / V_m by
  [(gamma+1)(gamma+2)/8 - gamma(gamma+1)/4] eps^2 = 0.111 eps^2. This is 1.1e-7 for runs a-c (eps = 1e-3) and 6.6e-5
  for run d (eps = 0.0244). Run d measured 6.36e-5 (L1.17), which matches. Run a measured 1.9e-6 (L1.6), so the
  numerical error there is about 2e-6.
- **Acoustic CFL.** The pressure amplitude changes by 6.0e-4 between CFL 20 (run a) and CFL 408 (run c) (L1.13).
  With the same PIMPLE settings (3 outer correctors, 2 pressure correctors), this solver does not show the large-CFL
  amplitude failure at 50 steps per cycle. Mass closure stays at 1e-11 or better and energy closure at 7e-5 or better
  at all three CFL numbers.
- **Piston-space cells, run d.** Heights 0.0512 to 0.1488 mm over the last cycle (L1.20, L1.21), ratio 2.91. With
  `pistonLinear` all piston-space cells have the same height at a given time, 0.1 mm (5 - x_p) / 5. So these are the
  extremes at the two ends of the stroke, not a spread across cells at one phase. The Fluent range the author quoted
  (0.0856 to 0.1001 mm) is at one phase and is not directly comparable. In `pistonLinear` at x_p = 0.72 mm the height
  is 0.0856 mm.
