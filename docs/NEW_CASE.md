# Building your own regenerator case from the L5 template

`cases/L5_regenSlice` is a 1-D column: hot chamber, hot HX, two screen sections, cold HX, cold chamber, driven by a
piston at each end. Every case file is generated by `mkCase.py` from one parameter file, `params_L5.yaml`. To
build another regenerator of the same layout, copy the directory and edit the parameter file. Edit the scripts
only where noted below.

    cp -r cases/L5_regenSlice cases/MY_regen
    # edit cases/MY_regen/params_L5.yaml (and, where noted, mkCase.py, system/ and the scripts)
    cases/MY_regen/Allrun 40          # build, write the case, mesh and run 40 cycles
    cases/MY_regen/Allclean

## Where each input lives

| input | file and key |
|---|---|
| operating frequency, mean pressure | `params_L5.yaml`: `operating_point.frequency_Hz`, `mean_pressure_Pa` |
| gas: R, c_p, mu(T), k(T) tables | `params_L5.yaml`: `gas` (written to `constant/thermophysicalProperties`) |
| geometry: cross-section area, zone extents along z | `params_L5.yaml`: `layout.area_m2`, `layout.zones.<zone>.z` (z = 0 at the matrix hot face) |
| cells per zone | `mkCase.py`: the `ncells` dictionary (`--grid-refine F` scales them all) |
| screen matrix: porosity, wire diameter, d_re, d_h, a_sf | `params_L5.yaml`: `porous_matrix.screen_500` and `screen_635` |
| drag: Darcy 1/alpha and Forchheimer C2 | the same entries: `inv_alpha_m2`, `C2_m1` (written to `constant/fvOptions`) |
| film coefficient (Gedeon-Wood screens: Nu = (1 + 0.99 Pe^0.66) beta^1.79) | the same entries: `nu_beta_factor` = beta^1.79, d_re and d_h. The correlation itself is `hsfModel screenGedeonWood` in `src/ltneFoam/ltneUpdate.H` |
| solid: matrix material and conduction fraction | `params_L5.yaml`: `solids.ksFrac`. The stainless c_p(T) and k(T) fits are `solidModel stainlessDeltaEC` in `src/ltneFoam/createLtneZones.H`; rho_s (7990) is set in `mkCase.py` |
| HX porosity, d_h, a_sf, drag | `params_L5.yaml`: `porous_hx` (Wakao film coefficient, `hsfModel wakao`) |
| HX solid temperatures | `params_L5.yaml`: `layout.zones.hot_hx.solid_T_fixed_K`, `cold_hx.solid_T_fixed_K`. The copper conductivity is in `mkCase.py` (`kcu`) |
| drive: piston displacement amplitude and phase | `params_L5.yaml`: `drive.hot_piston` and `cold_piston` (`displacement_amp_m`, `displacement_phase_deg`). The start-up ramp and the sign convention are in `mkCase.py`, `piston()` (see the L5 case README) |
| initial temperatures | `params_L5.yaml`: `initial_conditions.T_matrix_profile_z_m__T_K` (interpolated onto cell centres) and the two HX temperatures |
| time step | `system/controlDict`: `deltaT` (L5: one cycle / 2400) |

## Values tied to the 23 Hz template

These are hard-coded for L5. Change them together when the frequency or the time step changes:
- `system/controlDict`: `deltaT`, `writeInterval` (24000 steps = 10 cycles), and the `fieldAverage` `restartPeriod`
  (one cycle, 1/23 s).
- `Allrun`, `Allrun.continue` and `runLong.sh`: the factor 23 (cycles to seconds) and the steps per cycle (2400;
  4800 in the sensitivity run).

## Names the post-processing expects

`results.py` reads the monitor columns by name:
- zones `hot_hx` and `cold_hx`;
- face zones `hotFace`, `joint` and `coldFace` (written by `mkCase.py` at the matrix faces and the joint between the
  two screen sections);
- patches `hotPiston` and `coldPiston`.

A layout with other zones, for example a single screen section, needs matching changes to `mkCase.py` (`order`,
`planes`, the `zones` and `monitors` blocks) and to `results.py`.

## Before trusting a new case

Write the acceptance bars first (see `docs/VERIFICATION.md` for the L5 and L6 examples). Check periodicity (B6),
the energy closure (both the four-term and the six-term form, L5 Amendment A1), and the grid and time-step
sensitivity (`cases/L6_regenConvergence`). The cases are 1-D and serial.
